# 🎓 Student Toolkit

> A smart and modern productivity toolkit designed to make everyday student tasks easier.

Student Toolkit is a web-based collection of useful tools for students.  
It provides a simple, responsive, and modern interface for managing academic calculations and other student-related tasks.

---

## ✨ Features

- 📊 **CGPA Calculator**
- 📝 **Grade Calculator**
- 🧮 **Academic Calculations**
- 📱 **Responsive Design**
- 🌙 **Modern Dark UI**
- ⚡ **Fast and Lightweight**
- 🎨 **Clean and Student-Friendly Interface**
